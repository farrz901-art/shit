**文档编号**: PRD-2026-07-02-001

## 1. 背景与契机

我们正在为西门子电机手册做 "隐性规则挖掘与图谱构建" 项目. 整套手册是 PDF, 几百页, 既有目录章节, 又有几十上百个选型表, 又有"注意 / 不能 / 仅适用 / 必须 / 禁止"这种隐性规则段落. 此前做法: 工程师人工读 + 人肉录入知识图谱, 单本手册 2-3 周.

本次需求来源是 **DeepSeek 分享链接** (`https://chat.deepseek.com/share/wbmg0i1neb616saobg`), 提供了一套 "PDF → 结构化产物" 的 5 步方法论, 业内有人这么做但本项目还没有专用工具.

**业务痛点**:
- 工程师读 1 份 PDF 3 周, 无法 scale
- 隐性规则靠人眼, 漏读率高, 已多次出"互斥规则漏抽 → 上线后失效"的事故
- 知识图谱录入前没有 "预分析产物" 给业务方验收, 出错回流成本高

**机会**:
- 让工程师 / 业务方在 PDF 进知识图谱前拿到 1 份结构化产物 (目录 + 表格 + 规则段落), 先看清, 再决定要不要送抽取
- 把 3 周人工降到 1 天审 + 1 天修改

## 2. 目标用户

### 主要用户: 超级管理员 (本项目仅 1 类管理员群)

- **日常工作**: 维护手册内容, 给工程师派活, 把 PDF 送进图谱
- **典型场景**:
  - 收到业务方新 1 份 PDF 手册, 想知道里面有哪些章节 / 多少表 / 多少规则段落
  - 在送进知识图谱前, 想对产物做最终验收
  - 出错回流时, 想看到完整产物清单排查哪一步错的

### 间接受益方: 业务方 / 项目方

- 看 PRD / 验收报告, 不直接用工具
- 期望: 工程师交付速度从 3 周降到 1 天, 出错回流从 1 周降到 1 天

## 3. 用户故事

### 故事 1: 上传 1 份 D81.1 手册并看到预分析产物

```
作为 超级管理员,
我希望上传 1 份西门子手册 PDF (e.g. D81.1),
然后在 1 分钟内拿到 PDF 的:
  1. 完整章节结构 (章标题 + 层级 + 页码)
  2. 所有表格 (每个表格单独 1 个 CSV)
  3. 所有隐性规则段落 (关键词 "注意/不能/仅适用/必须/禁止" 命中)

以便我能快速决策: 这份手册值不值得送进知识图谱, 错在哪.
```

### 故事 2: 把所有产物一次性下载本地审

```
作为 超级管理员,
我希望能把上述所有产物 1 次性打成 zip 下载回本地

以便 我能用本地的 Excel / VSCode 离线打开看, 不用每次都登系统
```

### 故事 3: 看到处理进度 / 失败原因

```
作为 超级管理员,
我希望能:
  1. 上传后立刻看到 "处理中" 状态
  2. 处理完看到 "已完成" + 产物清单
  3. 如果失败看到明确原因 (e.g. "PDF 损坏", "无目录结构")

以便 我知道下一步是重试还是报修
```

### 故事 4: 看历史所有任务的清单

```
作为 超级管理员,
我希望能看到过去 30 天所有预分析任务 (谁传的, 何时, 状态, 产物数)

以便 我能:
  1. 回顾哪些手册已处理过
  2. 找丢失的产物
  3. 删失败的任务
```

## 4. 功能范围

### 4.1 In Scope (本期做)

| 编号 | 功能 | 验收标准 |
|---|---|---|
| F1 | 上传单个 PDF (≤ 100MB) | 1 步操作, 上传后立刻返回任务 ID |
| F2 | 后台异步处理 | 上传后不阻塞, 用户去干别的, 处理完弹提示 |
| F3 | 产物: 章节结构 JSON | JSON 内含章标题 / 层级 / 页码, 章节数 ≥ PDF 真实章节数 - 1 (允许 1 章偏差) |
| F4 | 产物: 每个表格单独 CSV | 文件名 `page-N-table-M.csv`, N=页码 M=第几个表, 列名跟 PDF 表头一致 |
| F5 | 产物: 规则段落 CSV | 文件含 "注意/不能/仅适用/必须/禁止" 命中段落, 每行 1 段, 列含: 命中关键词 / 段落原文 / 页码位置 |
| F6 | 1 个页面: 任务列表 | 显示: 任务 ID / 文件名 / 上传时间 / 状态 / 产物数 |
| F7 | 1 个页面: 任务详情 | 显示: 状态 + 产物清单 (按文件类型分组) + 下载按钮 |
| F8 | 下载全部产物 (zip 打包) | 1 键下载, 解压后产物清单跟详情页一致 |
| F9 | 仅超管可见 | 非管理员账号看不到入口, 也调不通 API |
| F10 | 操作审计 | 上传 / 下载均记审计日志 (谁 / 何时 / 哪个任务) |

### 4.2 Out of Scope (本期不做, 留后续)

| 编号 | 不做项 | 备注 |
|---|---|---|
| NF1 | 跨页表格自动合并 | 单页表已够本期, 跨页合并属于下一版 |
| NF2 | 自动联动知识图谱抽取 | 本期产物仅供人看, 进图谱人工触发, 解耦更稳 |
| NF3 | 扫描件 / OCR 识别 | 本期假设 PDF 至少有可复制文字, 扫描件后续再说 |
| NF4 | 多 PDF 批量上传 | 单文件流程先稳, 批量后续 |
| NF5 | 章节自动摘要 | LLM 摘要后期增量, 本期产物原文 |
| NF6 | 实时秒级返回 | 1 分钟内完成即可, 用户感知不强 |
| NF7 | 多租户 / 多用户隔离 | 项目仅 1 类管理员群, 不隔离 |
| NF8 | 关键词白名单可视化编辑 | 关键词列表后台配置项 (configs/pre_analysis/rule_keywords.yaml), 本期不开放给超管 UI, **但支持文件级追加** (admin 改 yaml + 重启服务生效, 留运维出口) |

## 5. 用户体验与界面

### 5.1 入口位置

超管登录后 → 顶部导航加 1 个 "PDF 预分析" 入口 → 跟 "知识抽取" / "权限管理" 平级.

### 5.2 主页面: 任务列表

```
+-----------------------------------------------------+
|  PDF 预分析                              [+ 上传]   |
+-----------------------------------------------------+
|  ID          文件名         上传时间     状态   产物 |
+-----------------------------------------------------+
|  pa-3f8c...  D81_2021.pdf   07-02 14:20 完成    18  |
|  pa-7a2e...  D84_2021.pdf   07-02 09:11 完成    12  |
|  pa-9b10...  bad_pdf.pdf    07-01 22:01 失败     0  |
+-----------------------------------------------------+
                                        [下一页]  |
+-----------------------------------------------------+
```

### 5.3 详情页面

```
+-----------------------------------------------------+
|  ← 返回    任务 pa-3f8c...                          |
+-----------------------------------------------------+
|  文件: D81_2021.pdf    状态: ✓ 已完成    耗时: 28s |
+-----------------------------------------------------+
|  📁 章节结构                chapter_structure.json  |
|     6 章  23 节             下载                    |
|  📊 表格  (12 个)           tables/                 |
|     page-3-table-1.csv ...  全部下载                |
|  ⚠️ 规则段落  (87 段)        flagged_paragraphs.csv |
|                            下载                    |
|                                                     |
|              [📦 一键下载全部 (zip)]               |
+-----------------------------------------------------+
```

### 5.4 上传弹框

- 1 个文件选择框 (接受 `.pdf` 限定)
- 大小警告: > 50MB 警告, > 100MB 拒绝
- 提交后立刻弹 "任务已创建, 关闭弹框去列表看进度"

## 6. 验收标准 (业务验收, 跟 §4.1 F 列对齐)

### 6.1 Happy Path (主管验收)

| 步骤 | 期望 |
|---|---|
| 1. 拿超管 token 登录 | 看到 "PDF 预分析" 入口 |
| 2. 上传 1 份 50 页 PDF (D81.1 真手册) | 收到任务 ID, 列表显示 "处理中" |
| 3. 等 30-60s | 状态变 "已完成" |
| 4. 进详情页 | 看到 3 类产物: 章节结构 + 表格列表 + 规则段落数 |
| 5. 下载 zip 解压 | 1 个 `chapter_structure.json` + N 个 `tables/*.csv` + 1 个 `flagged_paragraphs.csv` |
| 6. 用文本编辑器打开 `flagged_paragraphs.csv` | 每行 1 段, 关键词命中段落确实含 "注意 / 不能" 等 |
| 7. 用 Excel 打开 `tables/page-N-table-M.csv` | 列名跟 PDF 表格一致, 行数合理 |

### 6.2 边界 / 失败 (工程师验收)

| 情况 | 期望 |
|---|---|
| 上传 1 个 0KB 文件 | 弹错: "文件不能为空" |
| 上传 1 个 .txt 假冒 PDF | 弹错: "只接受 PDF" |
| 上传 1 个损坏的 PDF (真 .pdf 头但内部错乱) | 任务状态: "失败", 详情页显示明确错误 |
| 上传 1 个无目录结构的扫描件 PDF | 任务状态: "已完成" 但章节产物标记 "无目录" |
| 上传 1 个无表格的纯文本 PDF | 任务状态: "已完成" 但表格产物标记 "0 表格" |
| 非管理员账号尝试访问 | 列表页 403, 上传 API 拒绝 |

### 6.3 性能验收

| 指标 | 目标 |
|---|---|
| 50 页 PDF 处理耗时 | ≤ 60s |
| 200 页 PDF 处理耗时 | ≤ 180s |
| 100MB PDF 不超时 | 后台跑, 不阻塞 UI |
| 详情页打开 | < 1s |
| 下载 zip | < 3s (100MB PDF 产物 zip ≤ 50MB) |

## 7. 时间盒与里程碑 (业务口径)

| 里程碑 | 业务可见 | 时长 |
|---|---|---|
| M1: 上传 + 处理能跑通 | 后端能上传 PDF 且后台处理 | 1.5 天 |
| M2: 产物 + 列表 + 详情可见 | 业务能看到产物清单 + 下载 zip | 1 天 |
| M3: 上线验收 | 主管真机走完 §6.1 7 步 + §6.2 6 路径 | 0.5 天 |
| **合计** | | **3 工作日** |

排期承诺: 3 个工作日交付, 含 1 天缓冲验收.

## 8. 不做的事 (业务口径, 跟前文 §4.2 对齐)

跟 §4.2 重复列出, 强调业务侧别误以为能做:

- ❌ 本期不能跟 "知识图谱抽取" 联动 — admin 上传预分析后, 还得手动再传 1 次知识图谱
- ❌ 本期不能识别扫描件 PDF
- ❌ 本期不能批量多 PDF 上传
- ❌ 本期不能编辑关键词白名单 (后台配置项, 不开放给超管 UI)
- ❌ 本期不能跨页表格合并

## 9. 风险与依赖

| 风险 | 影响 | 应对 |
|---|---|---|
| 部分老 PDF 无目录 outline | 章节产物空 | 任务不失败, 标 "无目录", 用户看其他产物 |
| 部分 PDF 加密 / 损坏 | 跑崩 | 任务状态标 "失败", 详情页显示明确错 |
| 大 PDF (100MB+) 处理超时 | 后台跑崩 | 后台异步, 不阻塞前端, 失败写审计 |
| 关键词命中数极少 (罕见手册) | 任务好像 "没干" | 详情页明确显示命中数 = 0, 不静默失败 |

依赖:

- 超管账号体系 (已有, [auth router](packages/service/src/auth/router.py))
- PDF 库环境 (已有, 项目内已用)
- 对象存储 (已有, 容量够)
