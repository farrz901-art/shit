## 目标

1. ruff `E402` 启用, src 业务代码函数内 import 必须有动机
2. 杜绝"无理由函数内 import" (没重依赖 / 软依赖 / 防循环任一动机的)
3. 跟项目铁律对齐: noqa 必须带具体错误码 + 中文注释

## 不做

- 不强制 tests/ 改 E402. test 文件内函数内 import 多为 mock fixture / `importlib` 动态加载 / `TYPE_CHECKING` 守卫, 强制挪顶会破坏 mock.patch 上下文, 改造价值低, 不在本期范围
- 不动 `src/__init__.py` 函数内 dynamic router 注 (防循环, 改架构超出本期)
- 不动 `src/retrieval/vector_store.py` / `src/core/lifespan.py` 等明显 lazy 重依赖 (动机合理, 加 noqa 即可)
- 不改 ruff 其它规则 (`W` / `I` / `UP` / `F` 不动)

### 2. src 改动原则

按函数内 import 动机分类, 区别处理:

**A. 允许 (加 `# noqa: E402` + 动机注释, 不挪)**

- 重依赖 lazy (langchain_postgres / pynvml / mineru / deepeval / boto3 / docker 等)
- 软依赖 (try/except ImportError 探测可选库)
- 防循环 (顶层 import 触发循环链)
- 模块重命名 / 局部别名兼容 (避免全仓 grep-replace)

**B. 必须挪顶部 (无合理动机)**

每处具体行号在 writing-plans 阶段 `grep -nE "^[[:space:]]+(from|import)" packages/service/src/<file>` 精确取得.

### 允许的 3 种函数内 import

必须紧贴函数体顶部, 上方留 1 行空行 + 1 行中文注释说明动机 + `# noqa: E402`:

1. **重依赖 lazy**: 模块加载慢 (langchain_postgres / pynvml / mineru / deepeval) 或启动期不需要
2. **软依赖**: `try / except ImportError` 探测可选库 (langfuse / tqdm 等)
3. **防循环**: 顶层 import 触发循环依赖链

模板:

​```python
def get_vector_store(...):
    # 重依赖 lazy: langchain_postgres 冷启动 1.2s, 非向量路径不需要
    from langchain_postgres import PGVectorStore  # noqa: E402

def optional_langfuse_trace(...):
    # 软依赖: langfuse 未装时降级到本地 logger, 不抛 ImportError
    try:
        from langfuse import Langfuse  # noqa: E402
    except ImportError:
        Langfuse = None

def register_chat_jobs():
    # 防循环: 顶层 from ..chat.service 会触发 import chain
    from ..chat.service import hard_delete_old_soft_deleted  # noqa: E402
​```

## 风险

- **挪顶部触发循环 import**: 实施期逐文件 `uv run python -c "import src.<module>"` 验证启动期无 ImportError. 失败则改回原位 + `# noqa: E402` + 注释 "防循环"
- **挪顶部改变 import 时序副作用**: 极少数 lazy 是为了延迟模块副作用 (例如 `from src.core.token_cache import invalidate_token` 在请求处理时才 import, 启动期不引入), 实施期若发现 import 时序影响 (例如启动变慢 / 模块加载顺序 bug), 撤回该挪动, 加 `# noqa: E402` + "lazy 推迟副作用" 注释
- **CLAUDE.md 章节太长**: 当前 200+ 行, 新章节 ~40 行, 不会过度膨胀
- **ruff E402 与 ruff 默认 E 集合重叠**: `extend-select` 加 E402 不会跟 `select = ["E", "F"]` 默认冲突, 已核对 ruff 0.11.x 文档
